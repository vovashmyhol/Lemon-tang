# 🍋 Lemon Ninja — Telegram Mini App

Простая и залипательная игра в стиле Fruit Ninja с лимонами и бомбами для Telegram Mini Apps.

## 🎮 Особенности геймплея
- **Свайп-лезвие:** Реагирует на пальцы на мобильном и мышь на ПК с красивым неоновым следом.
- **Сочные разрезы:** Лимоны (целые и с дольками в разрезе) распадаются на 2 половинки по углу среза с разлетом мякоти и брызг сока.
- **Бомбы 💣:** Вылетают среди лимонов с горящим фитилем и искрами. При разрезании — взрыв, тряска экрана и конец игры.
- **Редкий золотой лимон ✨:** Даёт +50 очков и звонкий звук.
- **Система комбо:** Разрежь 2+ лимона одним свайпом, чтобы получить множитель и бонусные очки.
- **Web Audio API:** Звуки взмахов, сочных брызг, взрыва и комбо синтезируются процедурно (работают без интернета и загрузки mp3).
- **Telegram Mini App SDK:** Подключен `telegram-web-app.js`, виброотклик (Haptic Feedback) на смартфонах при разрезах и взрывах.

## 🚀 Как запустить для проверки

### Способ 1: Без установки
Просто откройте файл `index.html` двойным кликом в любом браузере (Chrome, Edge, Safari, Firefox).

### Способ 2: Локальный сервер
В папке проекта выполните в терминале:
```bash
npx serve -l 3000
```
Затем откройте в браузере `http://localhost:3000`.

## 📲 Как подключить к Telegram Bot
1. Откройте в Telegram бота **@BotFather**.
2. Введите `/newbot` (или выберите существующего через `/mybots`).
3. В меню бота выберите **Bot Settings** -> **Menu Button** -> **Configure menu button** (или создайте Web App через `/newapp`).
4. Укажите ссылку на опубликованную игру (например, залитую на GitHub Pages, Vercel, Netlify или туннель `ngrok`).
